# 💼 CRM & Billing Pro

> Sistema de escritorio moderno y modular enfocado en la gestión comercial, control de clientes (CRM), inventario con categorías, control de empleados y emisión de facturas profesionales con generación automática de documentos PDF.

---

## 🚀 Características Principales

* **👥 Módulo CRM (Clientes):** Registro detallado de clientes con control de nombre, correo, teléfono y dirección.
* **👨‍💼 Gestión de Empleados:** Registro y actualización de vendedores vinculados directamente al emisor de cada factura.
* **📦 Inventario Inteligente y Categorías:** Control de stock, precios, empresas/marcas asociadas y clasificación por categorías con catálogo visual interactivo.
* **🛒 Carrito Multiproducto:** Permite agregar múltiples productos al carrito con sus respectivas cantidades y calcular el total de forma dinámica antes de emitir la factura.
* **🧾 Facturación y Reportes PDF:** Generación automática de facturas comerciales formales utilizando *ReportLab*, almacenadas de forma ordenada en la carpeta `/facturas_pdf`.
* **📊 Analíticas y Gráficos:** Visualización integrada en tiempo real del rendimiento de ventas por producto mediante gráficos estadísticos con *Matplotlib*.
* **🔄 Migración Automática de Base de Datos:** Sistema resiliente en SQLite que adapta la estructura de tablas y columnas automáticamente ante actualizaciones sin perder datos previos.

---

## 🛠️ Tecnologías Utilizadas

* **Python 3.x**
* **CustomTkinter** (Interfaz gráfica de usuario moderna)
* **SQLite** (Base de datos relacional local)
* **ReportLab** (Generación de facturas en formato PDF)
* **Matplotlib** (Gráficos estadísticos analíticos)
